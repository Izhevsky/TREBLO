# TREBLO Astra Audio v2.7 — оценка изоляции настоящей DrumSep-модели

**Цель:** впервые оценивать отдельно качество извлечённых kick/snare/toms/hi-hat/ride/crash на *известных* исходных синтетических партиях, а не только точность обратной суммы.

Тест: шесть самостоятельно сгенерированных барабанных сигналов в 44,1 кГц stereo, один совместный микс. Система запускает **настоящую** модель `MDX23CInference` с SHA-256 проверкой публичных весов `drumsep-6stem` через библиотеку `openmirlab/mdxnet-infer` (зафиксированный commit `cb4779eedeca4f55ba498df8e234e2b5f4b90aaf`). Создаются шесть прогнозов и вычисляются SI-SDR, корреляция каждого прогноза с настоящей отдельной партией, ошибка суммирования и энергетический баланс. Не используется музыка пользователя.

Метрики **не доказывают**, что модель чисто разделяет Golden Teeth: оригинальный синтетический барабанный тест не эквивалентен музыкальному миксу. Итоговый мастер **не** заменяется автоматически.

Для локального воспроизведения:

```bash
PYTHONPATH=tools/mastering python -m unittest discover -s tests -p 'test_drumsep_reference_benchmark.py' -v
PYTHONPATH=tools/mastering python tools/mastering/drumsep_reference_benchmark.py \
 --seconds 7 --device cpu --allow-download --output ./qc_drumsep_v27.json
```

Второй вызов скачает ~438 МБ внешних модельных весов только при явном флаге. Веса имеют неясную лицензию; коммерческий запуск без правовой проверки не разрешён. JSON не содержит аудиосэмплов, однако подробные измерения доступны для инженерной оценки.

После проверки теста на GitHub потребуется локальная аудиосреда с моделью и пользовательским `drums golden teeth.wav` для настоящего вхождения в Golden Teeth. Не передавать пользовательские WAV в публичные CI-артефакты, а также не публиковать модельные веса.
