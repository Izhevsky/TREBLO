# TREBLO / Astra Audio v2.9 — восстановление исходного float32-микса Golden Teeth v2.3

## Что реально подтверждено

Исходная готовая версия `Golden_Teeth_Transient_Precision_v2_3_24bit.flac` сохранена, но её **неотлимитированный исходный микс** не был доступен в текущей файловой копии. В рамках v2.9 восстановлен новый float32 WAV из **оригинального WAV + шести исходных стемов**, опираясь на настройки TREBLO v2.1 и v2.3 из репозитория. Это не нейросетевое разделение и не новый мастеринг. Настоящий DrumSep на Golden Teeth ещё не запускался.

При перепроверке мастер-процессом Astra/FFmpeg на всех 10 553 345 кадрах:

- Sample rate 44 100 Гц, два канала, 239.304875 с.
- LUFS-I: -13.70; true peak: -1.54 dBTP; LRA: 3.4 LU.
- Корреляция готового восстановленного мастера с официальным v2.3 **0.9999999999999902** (полный трек).
- Относительная ошибка полного сигнала: **-136.807 dB** (содержимое декодированных FLAC).
- Максимальная разница отсчётов: 1.1920928955078125e-07 (один шаг 24-bit).
- Точное совпадение декодированных отсчётов: 94.72%. Вариация из-за разного экземпляра TPDF-дизеринга не является дефектом.
- Контроль суммы шести исходных стемов относительно оригинала: -36.755 dB, худшее 10-с окно -28.046 dB. Это исходная разница суммирования, не точность изоляции.
- STFT-псевдостемы v2.3 реконструируются с максимальной ошибкой 5.55e-17 в float64.
- Это почти точное воспроизведение **после нового мастеринга**, но не заявление о побитовом совпадении float32 WAV с удалённым промежуточным файлом.

## Воспроизводимый запуск (локальный Windows/PowerShell)

Положить исходный WAV и шесть файлов `[name] golden teeth.wav` в один каталог. FFmpeg должен быть доступен в PATH; требуются numpy, scipy, soundfile, pedalboard.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install numpy scipy soundfile pedalboard

python tools/mastering/rebuild_v23_unlimited.py `
  --root "D:\Music\Golden Teeth" `
  --output "D:\Music\GT_v29_restore_fresh"

# Только сверка! Не заменяет исходный одобренный мастер.
python tools/mastering/verify_rebuild_v23.py `
  --workdir "D:\Music\GT_v29_restore_fresh" `
  --reference "D:\Music\Golden Teeth\Golden_Teeth_Transient_Precision_v2_3_24bit.flac"
```

**Обязательно использовать пустой новый каталог `--output`.** Скрипт не запускается поверх старого каталога, чтобы не подхватить неверные промежуточные файлы. Он не изменяет исходные WAV и не загружает музыку в облако.

Результат: `GT_v23_unlimited_rebuilt_float32.wav` — неотлимитированный кандидат. Для нейросетевого мастера направлять через `neural_master_pipeline.py` из PR #11 с реальными SHA-проверенными нейростемами, а не мастер-FLAC.

## Обязательные ограничения

1. Без весов нейромодели реальный Neural Kick Master не появляется. Текущий новый файл — **восстановленный float32 baseline**, а не результат DrumSep.
2. Восстановленный мастер, использованный только для сопоставления, не заменяет ранее одобренный v2.3; он по аудиоданным практически идентичен предыдущему, но идентичность контейнерных хешей не гарантирована.
3. Уровень субъективной чистоты, улучшения удара бочки или хэтов **не оценивался**; новой художественной обработки не было.
4. SHA исходных файлов и точный список обработок сохранены в `rebuild_report.json`; проверка источников выполняется при каждом повторном рендере из нового каталога.
5. Веса DrumSep имеют неустановленную коммерческую лицензию; в публичный репозиторий не включать.
