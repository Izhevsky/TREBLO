# TREBLO / Astra Audio v2.3 — Transient Precision

**Статус:** экспериментальный мастер Golden Teeth, не заменяет одобренный Studio Rework или v2.2 до пользовательского A/B.

## Цель и ограничения

В ответ на оценку v2.2 («чуть чище») выполнена ещё более аккуратная, **стереосвязанная** динамическая обработка спектральных прокси барабанов. Это **не** нейросетевое выделение kick/snare/hats, а STFT-маски с остатком, которые точно суммируются в исходный drums-стем. Инструментальный bleed возможен. Новых нот/ударов/синтезаторов нет.

Исходные WAV и шесть выровненных стемов неизменны; их SHA-256 проверяются. Запись пересобирается из **неотлимитированного** исходного микса: original + Σ(stem_after − stem_before). Треки previous mastered FLAC в обработку не подаются.

## Обработка

- Зависимости: прежняя ветка Astra Audio v2.1 + Drum Substem v2.2; numpy, scipy, soundfile, pedalboard, FFmpeg (SoXR).
- Оконный STFT split пяти спектральных прокси в \`drum_substem_dsp.py\`.
- Быстрый/медленный RMS с шагом 5 мс формирует мягкий onset envelope 0–1, **один для обоих стереоканалов**.
- Ограниченные gain-изменения, дБ:

| Прокси | Тело | Дополнительно на атаке |
|---|---:|---:|
| Kick | +0.40 | +0.13 |
| Hats | +0.36 | +0.38 |
| Snare / clap | −0.44 | −0.18 |
| Cymbals | +0.10 | 0.00 |

- Бас и other-стем не меняются сверх прежней базы v2.1. Структура оригинала и тайминг сохраняются.
- Из raw формируется float32-премастер на −6 dBFS sample peak, затем статический gain, лимитер FFmpeg с 4× SoXR, финальный FLAC24/16 с раздельным TPDF.
- \`render_v23_resumable.py\` хранит промежуточные стадии и верифицирует манифест SHA-256 при возобновлении.

## Воспроизведение (только с легально доступными исходниками)

Для Golden Teeth исходник \`LOFI HOUSE - deepsmeeth - golden teeth - Treblo.wav\` и шесть файлов \`[stem] golden teeth.wav\` должны лежать по указанным путям.

\`\`\`bash
python tools/mastering/render_v23_resumable.py \
  --original "/audio/LOFI HOUSE - deepsmeeth - golden teeth - Treblo.wav" \
  --stemdir "/audio" \
  --workdir "./work_v23" \
  --output "./delivery/Golden_Teeth_v23.flac" \
  --stage all
\`\`\`

При ограничении длительности выполнения можно отдельно вызывать \`--stage prepare\`, \`--stage mix\`, \`--stage master\`. При повторном запуске сохранённые промежуточные данные переиспользуются после проверки исходных SHA-256.

## QC и A/B

Проверено на полном Golden Teeth (239.304875 с, 44.1 kHz, 10 553 345 стереокадров):

| Параметр | Значение |
|---|---:|
| LUFS-I | −13.70 |
| dBTP (финальный файл) | −1.54 |
| LRA | 3.4 LU |
| RMS ошибки полного суммирования прокси | max absolute ≈ 5.55×10⁻¹⁷ |
| Корреляция v2.2/v2.3 в 4 окнах | 0.99999358 |
| RMS-разница v2.3–v2.2 в 4 окнах | −48.74 dB относительно v2.2 |
| Максимальная потеря при моносложении в 4 полосах на исследованных окнах | менее 0.38 dB |

Два A/B: v2.2→v2.3 и Studio Rework→v2.3, по три 12-секундные пары с началами 42/94/171 с, постоянное выравнивание по LUFS, без дополнительного лимитирования и с плавными краями.

**Оценка на слух:** пользователем ещё не проведена. В цифрах нет доказательства слышимого превосходства. Оба старых мастера остаются эталонами.
