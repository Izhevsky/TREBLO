# TREBLO / Astra Audio v2.9 — доказуемое восстановление источника v2.3

**Статус:** реальная проверка на полном Golden Teeth, 2 ноября 2026. Это не новый нейросетевой мастер: модель DrumSep на Golden Teeth не запускалась.

## Почему важен этот этап
В сквозном пайплайне Neural Kick v2.8 необходим **неотлимитированный float32 микс v2.3** (`raw_v23_float.wav`). Его не было среди сохранённых результатов прежних версий. Повторный лимитированный FLAC нельзя использовать как замену без двойной динамической обработки.

Теперь исходный WAV 48 кГц, шесть стемов WAV 44,1 кГц и исходные скрипты v2.1–v2.3 восстановили именно этот промежуточный микс. Входная реконструкция суммы стемов: корреляция 0.9998947897178357; ошибка −36.75457559328966 dB относительно оригинала; худшая из 24 десятисекундных полос −28.05 dB. Исходник сначала переведён в 44,1 кГц по старому процессу FFmpeg, **не через новый resampler**, чтобы избежать дрейфа PCM.

## Самое важное доказательство

Повторный рендер из восстановленного float32-премастера и оригинальный `Golden_Teeth_Transient_Precision_v2_3_24bit.flac`:

- 10 553 345 stereo frames, 44 100 Гц, PCM24 FLAC.
- **SHA-256 обоих контейнеров:** `17a6807531cf3a2bbfd36213ac5d620c22dfd65c0d227113004bdf417eb42c1e`.
- **Побитовое совпадение всего декодированного PCM:** ни одного различающегося отсчёта, максимальная разница 0.0, корреляция 1.0.
- Контрольные измерения нового мастера: −13.70 LUFS, −1.54 dBTP, LRA 3.4 LU.
- SHA-256 восстановленного unmastered float32 WAV: `35c535846d1eb6bdde4dbebb6cbc1008a0e2ae0beff2a649c20078bdf2cd6ac1`.
- SHA-256 восстановленного −6 dBFS float32 premaster: `fdc92d64314deb9874159d383a1a78319826b74a6917468565013a33f3548db1`.

Такое совпадение подтверждает воспроизводимость **данного конкретного входного набора**. Не утверждает, что новая звуковая обработка улучшила трек.

## Алгоритм повторения

Нужны локальные исходники, `tools/mastering/` из PR #11 и новая `verified_v23_baseline.py`:

```bash
python tools/mastering/verified_v23_baseline.py build \
  --original '/audio/LOFI HOUSE - deepsmeeth - golden teeth - Treblo.wav' \
  --stems-dir '/audio' \
  --reference-v23 '/audio/Golden_Teeth_Transient_Precision_v2_3_24bit.flac' \
  --workdir '/audio/new_v23_build'
```

`build` **отказывается писать в существующий каталог**. Стадии: `prepare`, `mix`, `master`. В конце проверяет SHA-256 и точное PCM-сравнение с эталоном; при несовпадении процесс сообщает об ошибке. Для повторной проверки без пересчёта:

```bash
python tools/mastering/verified_v23_baseline.py verify \
  --original '/audio/LOFI HOUSE - deepsmeeth - golden teeth - Treblo.wav' \
  --stems-dir '/audio' \
  --reference-v23 '/audio/Golden_Teeth_Transient_Precision_v2_3_24bit.flac' \
  --workdir '/audio/new_v23_build'
```

**Для v2.8** указывайте `--v23-unlimited '/audio/new_v23_build/raw_v23_float.wav'`. Нельзя вместо него указывать лимитированный v2.3 FLAC. `VERIFIED_V23_LINEAGE.json` содержит контрольные суммы.

## Контроль приватности
Ни Golden Teeth, ни исходные стемы, ни мастер не отправляются на GitHub: в публичный TREBLO добавляются **только код, тесты и технические показатели**. Коммерческая лицензия весов DrumSep остаётся неясной; модель ещё не запускалась локально на этом файле. Gold reference Studio Rework и v2.3 сохранены неизменными.

## Локальные тесты

`python -m unittest tests/test_verified_v23_baseline.py -v`

Пять тестов верификации, включая отрицательные случаи: сэмпл подменён, несовпадение сетки, неправильная разрядность, попытка повторной записи в рабочий каталог.
