# TREBLO / Astra Audio v2.1 — Golden Teeth Stem Delta Rework

**Статус:** реальный CPU-рендер из пользовательских стемов; проверен автоматическими тестами и QC. Впечатление на слух остаётся за пользователем. **Не заменяет автоматически предпочитаемый Golden Teeth — Studio Rework.**

## Что сделано

1. Зафиксированы SHA-256 исходного stereo WAV и всех шести WAV-стемов.
2. Исходный WAV 48 kHz стерео преобразован один раз в 44.1 kHz float32 на сетку пользовательских стемов (у всех 44.1 kHz, одинаковая длительность и число кадров).
3. Проведена полная проверка суммирования шести стемов. Корреляция исходного микса и их суммы = **0.9998947897**, относительная RMS-энергия невосстановленного остатка = **−36.7546 dB**; худшее 10-секундное окно −28.046 dB. Эти метрики не являются SDR против ground truth или оценкой качества самого разделения.
4. На индивидуальных стемах применены маленькие изменения через Spotify Pedalboard. Нет новых нот, ударных, реверба или дополнительного семплера.
5. Сборка только методом дельты: `out = original_resampled + Σ(processed_stem − original_stem)`. Невосстановленный остаток микса сохраняется. В отличие от `original + processed_stems` метод **не задваивает** существующие партии.
6. На other расширена только высокочастотная Side-составляющая (HPF 700 Hz, 4-й порядок, +7.5% от этой составляющей). Низ и исходный side басового стема остаются без дополнительного расширения.
7. Из итогового стереомикса подготовлен float32-премастер с sample peak −6.0 dBFS. Только из него выполнены статическое усиление, FFmpeg 4x SoXR, лимитер и TPDF к FLAC24 / FLAC16.
8. После экспорта измерены `loudnorm input_*` и независимо `ebur128` готового файла. Проверены целостность исходника и всех стемов, частота, число каналов/кадров, TP.
9. Подготовлено сравнение v2.1 с уже одобренным `GT_Studio_Rework_MASTER.flac` с выравниванием громкости по каждой A/B-паре. Это **не слепой тест**.

## Тональная обработка

| Stem | Эффекты | Пояснение |
|---|---|---|
| Drums | Peak +0.55 dB @ 65 Hz (Q .85); −0.25 dB @ 430 Hz (Q .8); HighShelf +0.48 dB @ 8.7 kHz | Чуть больше атаки/фундамента и воздуха, без нового кика/хэтов |
| Bass | Peak +0.35 dB @ 95 Hz (Q .75); −0.35 dB @ 320 Hz (Q .8) | Теплота без расползания по стерео |
| Other | Peak −0.40 dB @ 330 Hz (Q .85); +0.28 dB @ 2.9 kHz (Q .9); HighShelf +0.18 dB @ 9.1 kHz | Разборчивость, верх без резкости |
| Other Side | HPF 700 Hz, 4th order, +7.5% полосового Side | Низ не расширяется |
| Piano, guitar, vocals | Сохранены без изменений | Эти предоставленные стемы практически пусты в исследуемой композиции |

**Важно:** использованы именно предоставленные пользователем стемы. Не подтверждено, что они являются оригинальными проектными дорожками DAW, а не результатом разделения стереомикса. Их высокая взаимная согласованность проверена измерениями.

## Файлы

- `Golden_Teeth_Stem_Delta_Experimental_v2_1_24bit.flac` — основной мастер.
- `Golden_Teeth_Stem_Delta_Experimental_v2_1_24bit_16bit.flac` — совместимая 16-битная версия.
- `Golden_Teeth_Studio_Rework_vs_Stem_Delta_v2_1_AB.flac` — сравнение по 12 секунд на позициях 42, 94, 171 с; пара: Studio Rework → Stem Delta v2.1.
- `Golden_Teeth_Stem_Delta_Experimental_v2_1_24bit.qc.json` — оригиналы и SHA, QC, настройки, ограничение пиков, окна согласованности стемов.
- `extra_qc.json` — дополнительная проверка баса и глобальной стереокорреляции.
- `tools/mastering/stem_delta_rework.py` — исходник и аргументы CLI.
- `tools/mastering/astra_pedalboard.py` — существующий прозрачный мастеринг-движок из v2.0.
- `tests/test_stem_delta_rework.py` — новые проверки, плюс тесты из v2.0.

## Воспроизведение

```bash
python -m pip install pedalboard numpy scipy soundfile
# FFmpeg с поддержкой libsoxr должен быть в PATH
python tools/mastering/stem_delta_rework.py \
  --original "LOFI HOUSE - deepsmeeth - golden teeth - Treblo.wav" \
  --stems-dir . \
  --output Golden_Teeth_Stem_Delta_Experimental_v2_1_24bit.flac \
  --target-lufs -13.7 --ceiling-dbtp -1.4
python -m unittest discover -s tests -p 'test_*.py' -v
```

Папка стемов должна содержать `drums.wav`, `bass.wav`, `other.wav`, `piano.wav`, `guitar.wav`, `vocals.wav` **либо** исторические имена `drums golden teeth.wav` и т. д.

## Что улучшать следующим

- Сравнение при одинаковой громкости; если прежний Studio Rework звучит лучше — оставить его основным.
- Для действительно раздельных kick/hat/clap — проверить соответствующие источники или специализированную модель разделения ударных. Просто EQ всего drums не обеспечивает независимую коррекцию хэтов и бочки.
- Проверка кодеков AAC/MP3 и моно на отдельных проблемных участках. Не считать более высокую корреляцию гарантией лучшей локализации.
- Нативный phaselimiter пока отдельная ветвь. Настоящий end-to-end тест не проведён.

Ни один модуль не создаёт новые ноты/синтезаторы и не заявляет восстановления информации, уже потерянной при генерации или кодировании.
