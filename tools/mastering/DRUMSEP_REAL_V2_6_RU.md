# TREBLO Astra DrumSep v2.6 — real checkpoint CPU smoke

Переход от имитации модели к **настоящему тесту MDX23C DrumSep** с проверяемыми SHA-256 весов на коротком **синтетическом** аудиофрагменте. Исходник Golden Teeth и любые пользовательские аудиоданные **не выгружаются в GitHub**.

- Исходная модель и контрольная сумма берутся из `tools/mastering/drumsep_6stem_float_bridge.py` (v2.5).
- Установленная библиотека строго закреплена на ревизии OpenMIRLab `cb4779eedeca4f55ba498df8e234e2b5f4b90aaf` (5 октября 2026); веса автоматически скачиваются только в явно разрешённом тесте.
- Из генератора создаётся 2 секунды stereo float32 WAV при 44,1 кГц, с ударами бочки и короткими шумовыми хэтами.
- После настоящего `MDX23CInference.separate()` проверяются пять результирующих WAV float32 (`kick/snare/toms/hh/cymbals`), количество кадров, конечность отсчётов, энергия, SHA и ошибка обратной суммы.
- Ошибка обратной суммы **не является показателем отсутствия bleed или качества звука**, и критерий музыкального превосходства не заявлен.
- В GitHub Actions сохраняется исключительно JSON с QC; ни сами веса модели, ни готовые синтетические WAV в artifact не выгружаются.
- Лицензия исходных весов автором не разъяснена. Этот эксперимент — не разрешение коммерчески распространять модель.

Локально (после установки PyTorch CPU и указанной библиотеки):

```
PYTHONPATH=tools/mastering python -m unittest discover -s tests -p 'test_drumsep_real_smoke.py' -v
PYTHONPATH=tools/mastering python tools/mastering/drumsep_real_smoke.py --workdir ./work/test-real --cache-dir ./work/model-cache --device cpu --allow-download
```

**Запуск настоящего Golden Teeth** должен выполняться только в доверенной среде с доступом к оригинальным пользовательским файлам. v2.5 содержит защиту SHA и вывод float32, а v2.4 — безопасный расчет дельты. Ни один из этих этапов не производит новый Golden Teeth FLAC до проверки реального модельного вывода и пользовательского A/B.
