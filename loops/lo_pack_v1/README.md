# LO Pack v1

Six owner-supplied source loops for TREBLO / Strudel experimentation.

## Public-bank format
- OGG derivatives are published here to keep repository and browser-runtime size practical.
- Source material was supplied by the repository owner.
- No normalization, EQ, denoising, time-stretching, pitch correction, or creative processing was applied during preparation.
- Original MP3 files and 24-bit / 44.1 kHz WAV decode derivatives are retained in the private TREBLO Library.
